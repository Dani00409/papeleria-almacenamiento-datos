Sistema de Gestión de Papelería

Descripción del proyecto
Este proyecto consiste en el análisis, diseño y desarrollo de una solución de almacenamiento de datos para una papelería.
El sistema busca organizar y gestionar la información relacionada con productos, proveedores, clientes, ventas, compras e inventario, mediante el diseño de una base de datos estructurada.

Objetivo general
Diseñar e implementar una base de datos que permita administrar eficientemente la información y los procesos principales de una papelería.

Módulos del proyecto

Gestión de productos.
Gestión de categorías.
Gestión de proveedores.
Gestión de clientes.
Control de inventario.
Registro de ventas.
Gestión de detalle de ventas;
